## Deviations & root-caused fixes
1. **three r185 TSL has no chainable bloom/ssao/fxaa nodes** (`three.tsl.js` export list verified) — spec's `pass().pipe(bloom).pipe(fxaa)` isn't available in this version. Shipped dual path: WebGL addons bloom (real, tested) + WebGPU feature-detect. A three upgrade unlocks the TSL chain with zero code changes.
2. **three 0.185 dropped the UMD build** — embedded the self-contained `three.core.min.js` (ESM) via base64 blob import for the offline export.
3. **ESLint regressed on the vendored minified file** — added `public/**` to eslint ignores.
4. **GLB JSON chunks must pad with spaces (0x20)** — NUL padding breaks `JSON.parse` (caught by unit test).
5. **`R3F renderPriority > 0`** — verified in fiber v9 source: any subscriber with priority disables the automatic `gl.render` (line `if (!state.internal.priority && state.gl.render)`).
